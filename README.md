# BrightHaven Cleaning — Updated Website

Premium, mobile-friendly static website for BrightHaven Cleaning, Liverpool.

## Files
- `index.html` — website structure/content
- `styles.css` — navy/gold premium design, responsive layout and animations
- `script.js` — mobile menu, scroll effects, quote form and WhatsApp/email enquiry handling

## Facebook
The footer currently contains a placeholder. Replace the `href="#"` on `#facebookLink` in `index.html` with the actual BrightHaven Cleaning Facebook page URL.

## Important form note
The WhatsApp form works without a server: it opens WhatsApp with every submitted field already included.
The email button opens the customer's own email application with the full enquiry prepared. For automatic server-side email delivery without relying on the customer's email app, connect a form backend such as Formspree/Web3Forms later.

## GitHub Pages
Upload `index.html`, `styles.css`, `script.js` and this README to the root of the `main` branch, then use Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Domain
For a custom `.co.uk` domain, buy/register the domain, then add it in GitHub Pages under Custom domain and create the DNS records requested by GitHub at the domain registrar.
